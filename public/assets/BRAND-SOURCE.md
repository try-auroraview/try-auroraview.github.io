# AuroraView original brand source

The website uses the existing AuroraView repository artwork without reconstructing its geometry or changing its colors. A CSS white backing keeps the original PNG legible in both themes.

- [Canonical source](https://github.com/try-auroraview/auroraview/blob/2212459651b7eee39645755fc09fa600667148b2/assets/icons/auroraview-logo-text.png): `assets/icons/auroraview-logo-text.png`.
- Identical repository copy: `docs/public/logo.png`.
- [Website PNG](/assets/logo-original.png).
- [Machine-readable provenance](/assets/brand-source.json).
- SHA256: `18a69d6feb6bda0c778e6a352d96e08c1ebd77ce1e6d7bab1a0e666361bd1f3c`.

The repository also retains the [original symbol PNG](https://github.com/try-auroraview/auroraview/blob/2212459651b7eee39645755fc09fa600667148b2/assets/images/auroraview-logo.png), 4160 × 4096 pixels, identical to `gallery/public/auroraview-logo.png`. Its SHA256 is `d57a81904d71a91b15b1e216c4b29d96a9936bf02f43cd1ab48a75435cd37908`. This website uses the existing square wordmark above for its navigation and footer.

The existing README and VitePress site use this artwork. No original editable SVG, AI, EPS, or Blender source was identified in the inspected repository references. The unrelated small `gallery/public/logo.svg` is not used as the AuroraView brand mark.
